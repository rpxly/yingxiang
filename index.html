04 — THE DETAILS

不写字，
也能有原厂感。

边框的高级感不在花哨，而在克制。参数从 EXIF 自动填入，空字段连同分隔符一起收掉，导出的每一像素都与原图一致。

01 / EXIF

参数自己会写。

导入照片即刻读取机型、镜头、光圈、快门、ISO、焦距与日期。手机联名也认得出：小米自动映射 Leica，vivo 映射 ZEISS，OPPO 映射 HASSELBLAD。

02 / CLEAN

没有脏字符。

镜头缺失时，不会留下「f/2.8 · · ISO100」这种残句。空字段连同分隔符整段删除，每一行都保持完整、干净。

03 / LOSSLESS

原图，原样。

按原图像素重建画布，长边最高 6000px。JPG / PNG / HEIC / PDF 四种格式，支持批量串行导出，分辨率与预览完全一致。

TECH NOTE

所有几何值都以画布宽度的比例定义，同一份模板在 4000px 与 12000px 的图上完全等比。换一张照片，版式不会走形。
