DESIGN SYSTEM

一块玻璃的配方

iOS 26 的液态玻璃不是“高斯模糊 + 圆角”。它靠四层叠加：低饱和底色、背景折射模糊、 1px 镜面高光、深投影。再让玻璃后面永远有东西在缓慢流动，玻璃才会“活”。

A一屏只留一层玻璃

玻璃叠玻璃会糊成灰。面板、导航、拨轮同一时刻只出现一个。

B动效只做反馈

每个动效都对应一次操作结果，不做无意义的呼吸与漂浮。

C真实照片做底

玻璃后面永远是照片和水印，才能折射出相机的质感。

GRADIENT FIELD

背景是显影液

液态玻璃本身是透明的，颜色全部来自背后。背景用三层径向渐变 + 一层线性底： 左上主色、对角辅色、底部反光，按 6 : 3 : 1 配比；再叠两颗缓慢漂移的光斑。 玻璃折射的是它，不是一块纯黑。

6 : 3 : 1 配比 1.1s 交叉淡入 26–32s 光斑漂移 180% 玻璃饱和

版式联动：装裱 → 暖沙，杂志 → 靛蓝，暗房 → 雾松。点上面的色卡可以直接改手机背景， 再切一张版式，看它自己换色。

SIX INTERACTIONS

六个交互，都是反馈

按视频里的顺序拆解，每一条都给出触发、时序、参数与 Flutter 落地方式。右侧“在原型里试一下”会直接跳到手机上对应位置。

01FEEDBACK

完成反馈按钮

Morphing Completion

点「导出」胶囊收缩成圆形，对勾沿路径自绘，12 颗粒子向四周迸发，玻璃 toast 从顶部落下。导出格式收进右上角设置：上传什么格式，默认就导出什么格式。

0ms 按下120ms 胶囊→圆340ms 对勾自绘420ms 粒子640ms toast
FLUTTER AnimatedContainer 控制宽高与圆角；对勾用 CustomPainter + AnimationController 画 dash；粒子用 12 个 Positioned 与单个控制器错峰。
02LINKAGE

勾选联动

Linked Check

勾选一个字段，预览水印立即增删一行；环形进度从 4/6 长到 5/6，数字像里程表一样滚动，面板底色由雾青慢慢转向暖沙。勾选不是开关，是一次微小的“显影”。

180ms 勾选360ms 数字滚动450ms 进度环550ms 底色偏移
FLUTTER TweenAnimationBuilder<double> 驱动环与底色；水印用 AnimatedSwitcher；数字滚动用 ClipRect + Transform.translate，每格 11px。
03STACK

叠卡展开

Stack Unfold

三张「本周精选」叠在一处，轻点后按 55ms 间隔依次展开成扇形；再点一次，从最后一张开始整齐叠回。展开不是列表，是把一叠照片摊到桌面上。

500ms spring55ms stagger±10° 旋转0.965 scale
FLUTTER Stack + Transform；一个 AnimationController 用 Interval 给三张卡分段，展开 / 收起用正反两条时间轴。
04SNAP

吸附卡 + 画线

Snap Rail & Line

横向滑动版式条，松手后最近的一张自动吸附到中心；选中卡下方的手绘线 360ms 绘出，底部四段流程线同时向前推进一格。滑动有了落点，流程有了痕迹。

scroll-snap mandatory吸附半径 24px360ms 画线550ms 流程线
FLUTTER 用 PageView + PageController，或 ScrollEndNotification + animateTo；线用 CustomPainter 画 dash-offset。
05INERTIA

惯性光圈拨轮

Inertia Dial

上下拨动光圈环，环随手指惯性旋转，松手后摩擦减速、磁吸到最近刻度；拨过头会回弹。光圈值同步写回水印预览，像在拧一台真实相机。

24° / 刻度friction .92spring k150 · d17回弹越界
FLUTTER GestureDetector + AnimationController.unbounded；松手后 FrictionSimulation 接 SpringSimulation，Transform.rotate 渲染刻度。
06TRANSITION

横向推进转场

Directional Push

首页和模板墙是同一级的两页，切换时按方向横向推进：前进时新页从右侧滑入，旧页向左退场并稍微变暗；返回时两个方向对调。两边一起动，页面之间才有前后关系，不会像凭空换了一张图。

520mscubic-bezier(.32,.72,0,1)新页 ±100%旧页 -34% / .18
FLUTTER SlideTransition 叠一层 FadeTransition；前进用 animation、返回用 reverseAnimation 取相反方向，两侧同时位移。

落地建议

原型用 CSS backdrop-filter 近似折射；Flutter 端用 BackdropFilter + ImageFilter.blur 复刻，折射边缘可用 CustomPainter + 渐变描边 模拟。所有弹簧曲线统一为 cubic-bezier(.34,1.56,.64,1)，时长控制在 280–620ms。
